## 🌟 Featured Projects

### 🎌 Nihongo Talk

**AI-powered Japanese language learning platform** designed to help learners progress from beginner level to JLPT N1.

**Highlights:**

- 🎙️ Real-time AI Japanese speaking coach
- 🧠 AI-powered grammar and vocabulary feedback
- 🎌 JLPT N5 → N1 learning system
- 🈶 Kanji writing and stroke practice
- ⚡ Anki SM-2 spaced-repetition flashcards
- 📝 JLPT mock examinations
- 🗺️ Adaptive learning roadmap
- 👥 Real-time study room with WebRTC
- 🖥️ Admin and learning management functionality

**Stack:** React · TypeScript · Vite · Tailwind CSS · Supabase · PostgreSQL · DeepSeek · Gemini · WebRTC

### ⚡ Super UI CLI

A CLI tool for adding Super UI components directly into React projects.

```bash
npx @farhod_dev/super-ui add button
```

The CLI can initialize projects, detect package managers, add individual or multiple components, and install required dependencies automatically.

<a href="https://www.npmjs.com/package/@farhod_dev/super-ui-cli">→ View on NPM</a>
